# Guide : Ajouter plusieurs accompagnements et options à la fois

## 🎯 Nouvelle fonctionnalité

Vous pouvez maintenant ajouter **plusieurs accompagnements et options** directement lors de la création ou modification d'un plat, sans avoir à passer par le panneau "Gérer extras".

## ✨ Avantages

- ✅ **Gain de temps** : Créez un plat avec tous ses accompagnements et options en une seule fois
- ✅ **Moins de clics** : Plus besoin de créer le plat puis d'ajouter les extras séparément
- ✅ **Interface intuitive** : Ajoutez/retirez des champs facilement avec les boutons + et ×

## 📋 Comment utiliser

### 1. Créer un nouveau plat avec accompagnements et options

1. **Cliquez sur "Ajouter un plat"** (bouton bleu en haut à droite)

2. **Remplissez les informations du plat** :
   - Nom du plat
   - Catégorie
   - Prix
   - Image (optionnel)
   - Détails
   - Cochez "Plat disponible"

3. **Ajoutez des accompagnements** :
   - Descendez jusqu'à la section "Accompagnements"
   - Cliquez sur le bouton **"+ Ajouter"**
   - Un nouveau champ apparaît avec :
     - **Nom** : Ex. "Alloco"
     - **Qté gratuite** : Ex. 1 (le client reçoit 1 alloco gratuit)
     - **Prix (FCFA)** : Ex. 500 (prix pour chaque alloco supplémentaire)
     - **Disponible** : Coché par défaut
   - Cliquez à nouveau sur **"+ Ajouter"** pour ajouter un autre accompagnement
   - Cliquez sur **"× Retirer"** pour supprimer un accompagnement

4. **Ajoutez des options** :
   - Descendez jusqu'à la section "Options"
   - Cliquez sur le bouton **"+ Ajouter"**
   - Remplissez de la même façon que les accompagnements
   - Ex. "Fromage", Qté gratuite: 0, Prix: 200 FCFA

5. **Soumettez le formulaire** :
   - Cliquez sur **"Créer le plat"**
   - Tous les accompagnements et options seront créés en même temps !

### 2. Modifier un plat et ajouter de nouveaux extras

1. **Cliquez sur l'icône crayon** (jaune) sur la card du plat

2. **Modifiez les informations** du plat si nécessaire

3. **Ajoutez de nouveaux accompagnements/options** :
   - Utilisez les boutons **"+ Ajouter"** dans les sections Accompagnements et Options
   - Les nouveaux extras seront ajoutés aux extras existants
   - ⚠️ Les extras déjà existants ne seront PAS supprimés

4. **Enregistrez** :
   - Cliquez sur "Enregistrer"
   - Le message confirmera le nombre de nouveaux extras ajoutés

## 🎨 Différences visuelles

### Accompagnements
- **Fond vert clair** (#F0FDF4)
- **Bordure orange** (#D9542A)
- Pour les accompagnements de base (riz, frites, salade, etc.)

### Options
- **Fond jaune clair** (#FEF3C7)
- **Bordure jaune** (#F7B801)
- Pour les extras payants (fromage, viande supplémentaire, etc.)

## 📝 Exemples pratiques

### Exemple 1 : Riz au gras complet

**Plat** :
- Nom : Riz au gras
- Prix : 2500 FCFA
- Catégorie : Plats principaux

**Accompagnements** (cliquez 3 fois sur "+ Ajouter") :
1. Alloco - Qté gratuite: 1 - Prix: 500 FCFA
2. Plantain frit - Qté gratuite: 1 - Prix: 300 FCFA
3. Salade - Qté gratuite: 1 - Prix: 200 FCFA

**Options** (cliquez 2 fois sur "+ Ajouter") :
1. Poisson supplémentaire - Qté gratuite: 0 - Prix: 800 FCFA
2. Sauce pimentée - Qté gratuite: 0 - Prix: 100 FCFA

→ **Résultat** : 1 plat créé avec 3 accompagnements et 2 options en une seule soumission !

### Exemple 2 : Burger simple

**Plat** :
- Nom : Burger classique
- Prix : 1800 FCFA

**Accompagnements** :
1. Frites - Qté gratuite: 1 - Prix: 400 FCFA

**Options** :
1. Fromage - Qté gratuite: 0 - Prix: 200 FCFA
2. Bacon - Qté gratuite: 0 - Prix: 300 FCFA
3. Double viande - Qté gratuite: 0 - Prix: 500 FCFA

### Exemple 3 : Plat sans accompagnements

**Plat** :
- Nom : Salade César
- Prix : 1500 FCFA

→ Ne cliquez pas sur "+ Ajouter" si le plat n'a pas d'accompagnements ou d'options

## ⚙️ Fonctionnement technique

### Lors de la création
- Tous les accompagnements et options sont créés en même temps que le plat
- Un seul formulaire, une seule soumission
- Message de confirmation détaillé

### Lors de la modification
- Les nouveaux accompagnements/options sont **ajoutés** aux existants
- Les extras existants ne sont **pas supprimés**
- Pour gérer/supprimer les extras existants, utilisez le panneau "Gérer extras" (bouton +)

## 🔄 Workflow complet

### Option A : Tout créer en une fois (Recommandé pour nouveaux plats)
1. Créer le plat
2. Ajouter tous les accompagnements
3. Ajouter toutes les options
4. Soumettre
✅ **Terminé !**

### Option B : Créer puis compléter
1. Créer le plat seul
2. Plus tard, cliquer sur "Modifier"
3. Ajouter les accompagnements/options
4. Enregistrer

### Option C : Gérer les extras séparément
1. Créer/modifier le plat
2. Cliquer sur le bouton "+" (noir) pour "Gérer extras"
3. Utiliser le panneau latéral pour ajouter/supprimer un par un
4. Voir tous les extras existants et les gérer individuellement

## 💡 Conseils

1. **Planifiez vos accompagnements** avant de créer le plat pour tout ajouter en une fois

2. **Utilisez des noms clairs** :
   - ✅ "Alloco (banane plantain frite)"
   - ✅ "Riz blanc"
   - ❌ "Accomp 1"

3. **Quantité gratuite** :
   - Mettez 1 si le client a droit à 1 unité gratuite
   - Mettez 0 si c'est toujours payant
   - Mettez 2 si le client a droit à 2 unités gratuites

4. **Prix unitaire** :
   - C'est le prix pour CHAQUE unité supplémentaire
   - Si Qté gratuite = 1 et Prix = 500, le client paie 500 FCFA pour le 2ème

5. **Différence accompagnement vs option** :
   - **Accompagnement** : Généralement inclus ou avec 1 gratuit (ex: frites, salade)
   - **Option** : Généralement payant (ex: fromage, bacon)

## ❓ Questions fréquentes

**Q : Puis-je modifier un accompagnement après création ?**
R : Non, pour le moment vous devez le supprimer et le recréer. Utilisez le panneau "Gérer extras" (bouton +).

**Q : Que se passe-t-il si je clique sur "Créer" sans ajouter d'accompagnements ?**
R : Le plat sera créé normalement, sans accompagnements. Vous pourrez les ajouter plus tard.

**Q : Puis-je ajouter 10 accompagnements en une fois ?**
R : Oui ! Cliquez 10 fois sur "+ Ajouter" et remplissez tous les champs.

**Q : Comment supprimer un accompagnement que je viens d'ajouter ?**
R : Cliquez sur le bouton "× Retirer" à droite du champ. Le champ disparaîtra.

**Q : La limite de 5 Mo concerne-t-elle aussi les accompagnements ?**
R : Pour le moment, vous ne pouvez pas uploader d'images pour les accompagnements/options dans ce formulaire. Utilisez le panneau "Gérer extras" pour les images.

## 🎉 Résumé

Cette fonctionnalité vous permet de :
- ✅ Créer un plat complet en **une seule fois**
- ✅ Ajouter **autant d'accompagnements et options** que nécessaire
- ✅ **Retirer** facilement un champ si vous avez fait une erreur
- ✅ **Modifier** un plat et ajouter de nouveaux extras
- ✅ **Gagner du temps** en évitant les allers-retours

**Le panneau "Gérer extras" reste disponible** pour :
- Voir tous les extras d'un plat
- Supprimer un extra existant
- Ajouter un extra avec image

Les deux méthodes se complètent parfaitement ! 🚀
